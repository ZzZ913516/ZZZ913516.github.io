05

踩坑记录

— trial & error
git push 报 CONNECT tunnel failed 502+

本机 git 走了代理且代理不通。解决：改用 GitHub Contents API（PUT /repos/.../contents/...）直接上传文件，base64 编码内容，绕过 git 的代理链路。教训：API 比 git push 更适合受限网络。

Windows 凭据 CredFree 报 OverflowError+

ctypes 没声明 argtypes，把 64 位指针当 int 传溢出。解决：给 CredReadW/CredFree 设 argtypes，用 POINTER(CREDENTIAL) 传参，CredFree 用 ctypes.cast(ptr,c_void_p)。

读凭据得乱码，HTTP header 编码失败+

CredentialBlob 是 UTF-8 窄字节，不是 UTF-16 宽字符。用 wstring_at 会两字节合成非 ASCII 字符，导致 latin-1 编码失败。解决：ctypes.string_at(addr,size) + .decode('utf-8')。
